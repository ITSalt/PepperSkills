# Pepper Prompt Engineer

Переносимый CRAFT+ плагин превращает описание задачи в проверенный production-
ready промпт. Канонический скилл находится в `skills/pepper-prompt-engineer/`,
чат-адаптеры — в `adapters/chat/`.
