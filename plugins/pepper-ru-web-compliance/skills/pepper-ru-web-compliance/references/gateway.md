# РФ-транспорт аудита

Браузер, JS, cookies, доказательства и отчёт работают на компьютере пользователя.
Сервис предоставляет временный сетевой доступ и фиксированные методы реестров и
DNS/TLS. Он не запускает браузер и не принимает отчёты. Настройки VPN не меняются.

## Подключение

`managed` по умолчанию использует развёрнутый РФ-шлюз
`https://lts.itsalt.ru/ru-audit`. Пользователь устанавливает скилл/плагин и запускает
аудит: задавать адрес, регистрироваться или менять VPN не требуется.
`PEPPER_RU_GATEWAY_URL` — необязательное переопределение для другого развёртывания.
В пакет включён только публичный адрес; временный доступ выдаётся сервером при
запуске, общих токенов в дистрибутиве нет.
Клиент сначала проверяет `/v2/capabilities` и доверенный вход `/v2/diagnostic`
без списания квоты и обращения к произвольному сайту. Обычные HTTPS-запросы
к шлюзу учитывают прокси среды; дальше локальный браузер работает через адаптер
и российский выход. Запрет домена шлюза останавливает сбор с кодом диагностики.

`custom`: задайте `PEPPER_RU_AUDIT_PROXY` URL вида `http://логин:пароль@хост:порт`
или `https://логин:пароль@хост:порт`. Значения берутся из окружения, не аргументов
командной строки; спецсимволы учётных данных кодируются percent-encoding.
`--mode custom` явно требует эту настройку. API нашего шлюза не вызывается.

`PEPPER_RU_REGISTRY_PROXY` сохраняет прежний смысл только для отдельных
реестровых операций. В `audit.py` используется один транспорт всей сессии.

Для private CA шлюза предусмотрен `PEPPER_RU_GATEWAY_CA_FILE`; проверка имени и
цепочки остаётся включённой. Не устанавливается MITM-сертификат сайтов.

## Запуск и повтор

```bash
uv run --no-project --with playwright==1.56.0 python -m playwright install chromium
uv run --no-project scripts/audit.py https://example.ru --out artifacts/ --findings findings.json
uv run --no-project scripts/audit.py --offline --out artifacts/ --findings findings.json
```

URL сайта в примере — цель аудита, не адрес сервиса. Установка зависимостей
выполняется до выдачи доступа и может требовать интернета. Для полностью офлайн
повтора заранее подготовьте окружение/кэш uv. Артефакты нового запуска пишутся в
пустой каталог, чтобы не смешивать разные наблюдения.

Перед запросами к сайту выбранный транспорт обращается к `https://ipinfo.io/json`.
Только ответ с IP и страной RU разрешает сбор. Это наблюдение GeoIP, а не гарантия
доступности каждого сайта; антибот и иные ограничения отражаются отдельно.
При недоступности GeoIP сбор останавливается. Сессия уже выдана и квота списана.

Свой HTTP-прокси разрешает DNS назначения сам; неизвестные DNS-данные отмечаются
UNKNOWN. TLS проверяется через CONNECT. В managed DNS/TLS проверяет сервер.
Браузерные POST, iframe, JS, service worker и WebSocket проходят через транспорт.
Отправка пользовательских форм не добавлена. QUIC и WebRTC UDP отключены.

## Квоты managed

| Лимит | По умолчанию |
|---|---:|
| Выдачи на IPv4 или IPv6 /64 | 3 за скользящие 24 часа |
| Активные на IP / весь сервер | 1 / 20 |
| Срок | 15 минут, без продления |
| К клиенту / от клиента | 250 MiB / 10 MiB |
| Соединения одновременно | 32 |
| Новые соединения | 10/с, запас 20 |
| Установка / бездействие | 10 / 60 секунд |
| Трафик всего сервера | 20 GiB за скользящие 24 часа |

Считаются выдачи сессий, а не HTTP-запросы. CONNECT — непрозрачный поток;
внутренние запросы HTTPS не считаются по отдельности. Ошибка сайта не возвращает
запуск. Общий VPN-IP имеет общую квоту; смена IP ограничение обходит, поэтому
есть общие лимиты. Нельзя доказать неизменность публичного клиента; возможен
посторонний обмен в пределах временного доступа. Этот остаточный риск принят.

## Ошибки и доказательства

`daily_quota` / `active_session`: HTTP 429, Retry-After. `server_busy` /
`server_budget`: HTTP 503, выдача не списывается. `session_expired`, `session_closed`,
`traffic_limit`: доступ прекращён, уже открытые туннели закрываются.
`session_lost`: сервер перезапущен, прежний токен больше не действует.
`destination_forbidden`: непубличный или служебный адрес. `port_forbidden`: не 80/443.

Новый доступ автоматически не запрашивается. Потерянный ответ выдачи повторяется
один раз с тем же ключом и параметрами; смена исходящего IP не создаёт второй запуск. При отказе можно дождаться Retry-After
или явно запустить аудит со своим РФ-прокси. Прямого fallback нет.

`manifest.json.network` содержит режим, наблюдаемый выход, начало/конец,
срок действия, полноту и причину ограничения, без пароля. Неполные артефакты
сохраняются; выводы об отсутствии проблем становятся UNKNOWN. Предварительные
статусы и доказательства остаются в пояснениях, но итоговые статусы не повышаются. Данные реестров сохраняются в
`registries/` с датой источника, доверием и ошибками; недоступность не означает
отсутствие записи. Смысловой анализ работает по этим файлам.
