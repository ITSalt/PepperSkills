# Формат плана исправлений

Часть II объединённого документа и отдельный `remediation-plan.md`.
План — для разработчика: каждая задача исполнима без чтения части I.

## Приоритеты

- **P0** — нарушения по нормам высокой и критической тяжести.
- **P1** — остальные нарушения.
- **P2** — риски по нормам высокой и критической тяжести.
- **P3** — остальные риски.

EXTERNAL и UNKNOWN задачами не становятся: первые — вопросы владельцу в части I,
вторые — технический сбой, который устраняется повторным запуском.

## Поля задачи

| Поле | Содержание |
|------|------------|
| Правила | ID всех объединённых правил |
| Что обнаружено | Факт из части I одной-двумя фразами |
| Текст правки утверждает | Для правок юридических текстов: владелец или юрист |
| Где | Страницы, запросы, селекторы; подтверждённые места правки из оценки |
| Перечень | Поимённо: неописанные cookie, отсутствующие разделы, лишние поля |
| Что сделать | Конкретная правка из смысловой оценки, находки или правила |
| Критерий приёмки | Проверяемое состояние; повторный аудит даёт по правилу ОК |

Первым вариантом правки для ненужного сервиса или пустого контейнера GTM
предлагается удаление. Задачи с общей правкой объединяются (баннер и запуск
тегов до выбора — одна задача), критерии приёмки сохраняются по каждому правилу.
Нормы и санкции остаются в части I.
