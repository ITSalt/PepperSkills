# Локальные снапшоты реестров

Этот каталог пуст в репозитории и в релизе — и это осознанное решение.
`*.json` здесь под `.gitignore`, а сборка `.skill` вырезает их из архива.

## Почему снапшоты не поставляются

Скилл забирает реестры сам: `registries.py update` тянет первоисточник и
кладёт результат в локальный кэш (`~/.cache/pepper-ru-web-compliance/`).
Снапшот — третий уровень отката, на случай когда недоступны и источник, и кэш.

Соблазн положить снапшот в комплект понятен, но для проверки на соответствие
закону он вреден. Реестр иностранных агентов пополняется еженедельно. Архивная
копия в дистрибутиве даёт не «данных нет», а тихое **ложное «упоминаний не
найдено»** — по списку, в котором нужного лица ещё нет. Для владельца сайта это
хуже честного отказа проверить: он получает заключение «чисто» и не делает
ничего.

Отсюда правило: реестр недоступен и кэша нет — статус `UNKNOWN` и указание,
что делать. Никогда не `PASS` по данным, которых у скилла не было.

Побочные плюсы: репозиторий не пухнет, копии снимков не копятся в истории git
навсегда, и не нужно обновлять их к каждому релизу, чтобы они не гнили.

## Как сделать снапшот себе

Имеет смысл, если вы работаете в офлайне или канал до ведомственных хостов
нестабилен.

```bash
python3 scripts/registries.py update --registry minjust_extremist_orgs
cp ~/.cache/pepper-ru-web-compliance/registries/minjust_extremist_orgs.json \
   assets/registries-snapshot/
```

Для реестров, чей хост недоступен (`reestrs.minjust.gov.ru` отвечает не
отовсюду), выгрузите файл вручную со страницы реестра и подайте напрямую:

```bash
python3 scripts/registries.py import \
  --registry minjust_foreign_agents \
  --file ~/Downloads/reestr.xlsx \
  --as-snapshot
```

Проверить, что откуда берётся:

```bash
python3 scripts/registries.py status
```

## Доступность источников

| Реестр | Источник | Доступность |
|--------|----------|-------------|
| `minjust_extremist_materials` | CSV Минюста | стабильно |
| `minjust_extremist_orgs` | HTML Минюста | стабильно |
| `fsb_terrorist_orgs` | HTML ФСБ | стабильно |
| `minjust_foreign_agents` | `reestrs.minjust.gov.ru` | отвечает не отовсюду, нужен ручной импорт |
| `minjust_undesirable_orgs` | `reestrs.minjust.gov.ru` | то же |
