# Происхождение материалов

Скилл `pepper-ru-web-compliance` распространяется по [MIT](./LICENSE).
Ниже — всё, что пришло извне, и на каких условиях.

## Код

Заимствованного кода нет. Скрипты написаны для этого скилла и используют только
стандартную библиотеку Python 3.10+; файл `scripts/requirements.txt` пуст по
существу.

Существующие открытые проекты со схожей задачей рассматривались как источник
идей. Ничего из них не копировалось: у рассмотренного репозитория
`lawcheck/lawcheck` лицензия не указана вовсе, а отсутствие лицензии означает
«все права защищены», а не «делай что хочешь».

## Опциональные зависимости

| Компонент | Лицензия | Как используется |
|-----------|----------|------------------|
| [Playwright](https://playwright.dev) | Apache-2.0 | ставится пользователем отдельно, в поставку не входит; без него сбор идёт без рендера |

## Сертификат

`skills/pepper-ru-web-compliance/assets/ca/globalsign-gcc-r3-dv-tls-ca-2020.pem` — промежуточный сертификат
удостоверяющего центра GlobalSign. Публикуется самим УЦ для достройки цепочки
доверия и берётся из поля Authority Information Access серверного сертификата
`reestrs.minjust.gov.ru`. Нужен потому, что сервер отдаёт неполную цепочку;
проверка сертификата при этом остаётся включённой. Отпечаток и срок действия —
в `skills/pepper-ru-web-compliance/assets/ca/README.md`.

## Правовые данные

Нормы, статьи КоАП и суммы санкций в `scripts/rules.yaml` — сведения из
нормативных актов Российской Федерации. Официальные документы государственных
органов не являются объектами авторского права (п. 6 ст. 1259 ГК РФ).
Формулировки требований написаны заново, дословных цитат нормативных текстов
файл не содержит.

## Госреестры

Скилл загружает пять государственных реестров с сайтов Минюста и ФСБ России во
время работы. Данные реестров публичны и публикуются ведомствами для
неограниченного круга лиц. Архивные копии реестров в поставку **не входят** —
см. `skills/pepper-ru-web-compliance/assets/registries-snapshot/README.md`.

Зеркало [`ITSalt/ru-registries-mirror`](https://github.com/ITSalt/ru-registries-mirror)
— отдельный проект тех же авторов; оно перепубликует данные ведомств в
машиночитаемом виде с указанием источника и времени снятия.
