# Поддержка RU Web Compliance

Технические вопросы и ошибки: [Issues PepperSkills](https://github.com/ITSalt/PepperSkills/issues).
Контакт издателя из метаданных проекта: info@itsalt.ru.

В обращении укажите версию пакета, клиент и его версию, операционную систему,
команду запуска, ожидаемое поведение и минимальный воспроизводимый пример.
Для неправильной квалификации приложите ID правила, обезличенную цитату и источник.

Не публикуйте в Issues cookie, токены, HAR с персональными данными, содержимое
закрытых страниц или refusal-storage-state.json. Вместо полного архива приложите
минимальную обезличенную фикстуру. Не отправляйте юридически значимые оригиналы.

Поддержка проекта не заменяет юридическую консультацию. Срок ответа не гарантирован.
