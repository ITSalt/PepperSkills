# Установка

Скилл поставляется в двух изданиях: полное для Claude и урезанное для GPT. Ниже
— как поставить каждое и что в каком окружении реально работает.

## Что работает где

Проверка сайта — это обход страниц браузером, запросы к госреестрам и сборка
PDF. Что из этого доступно, зависит от среды, в которой исполняются скрипты
скилла.

| Окружение | Обход сайта | Госреестры | PDF | Что остаётся |
|-----------|-------------|------------|-----|--------------|
| **Claude Code** (и Cowork с доступом к компьютеру) | да | да | да | полная проверка |
| **Claude в браузере и десктопе** | нет | зависит от настроек сети у среды исполнения | да | правила, разбор принесённых артефактов, сборка записки |
| **Claude API** с code execution | нет | нет | да | то же, что выше |
| **GPT** (Custom GPT, ChatGPT, API) | нет | нет | нет | чек-лист ручной проверки, модель ведёт человека |

У среды исполнения в приложениях Claude нет Playwright и, как правило, нет
выхода в интернет — сеть там управляется настройками владельца аккаунта или
администратора организации. Поэтому сбор фактов с сайта возможен только в
Claude Code, где скрипты выполняются на машине пользователя.

## Claude Code

Скопировать каталог в папку скиллов под именем, совпадающим с полем `name`
в `SKILL.md`:

```bash
# личные скиллы
cp -R anthropic ~/.claude/skills/pepper-ru-web-compliance

# или для конкретного проекта
cp -R anthropic <project>/.claude/skills/pepper-ru-web-compliance
```

Проверить, что скилл виден: в новой сессии спросить «проверь сайт example.ru на
соответствие требованиям РФ».

## Claude в браузере и в десктопном приложении

1. Включить исполнение кода: **Settings → Capabilities → Code execution and
   file creation**. На тарифах Team и Enterprise это делает администратор в
   **Organization settings → Skills**. Без этого скилл не запустит ни один
   скрипт.
2. Скачать `pepper-ru-web-compliance.skill` из
   [последнего релиза](https://github.com/ITSalt/PepperSkills/releases/latest).
3. Открыть **Customize → Skills** (claude.ai/customize/skills), нажать
   **Add → Upload skill**.
4. Перетащить файл в поле загрузки и нажать **Save**. При сохранении
   запускается проверка безопасности — она читает содержимое архива, включая
   скрипты.
5. Скилл появится во вкладке **Yours**; там же он включается и выключается.

Формат архива подходит: внутри одна папка `pepper-ru-web-compliance/` с
`SKILL.md` в корне. Диалог принимает `.skill` и `.zip`.

**Чего ждать в этом окружении.** Обхода сайта не будет: Playwright в среду
исполнения не входит, ставить его некуда. Скилл остаётся полезным как разбор:
можно принести собственные артефакты (HTML страниц, сетевой лог, тексты
политики и оферты) и получить записку с чек-листом, нормами и планом правок.
Если у вашей организации сетевой доступ для исполнения кода открыт, подтянутся
и госреестры.

Полный автоматический прогон — только через Claude Code.

## GPT: Custom GPT

1. Открыть [chatgpt.com/gpts/editor](https://chatgpt.com/gpts/editor), вкладка
   **Configure**.
2. В **Instructions** вставить текст из блока `System Prompt` файла
   [`openai/system-prompt.md`](../openai/system-prompt.md).
3. В **Knowledge** загрузить
   [`openai/manual-checklist.md`](../openai/manual-checklist.md) — 25 пунктов
   проверки с нормами, суммами санкций и способом проверки каждого.
4. Инструменты можно не включать: обход сайта в этом издании не
   предусмотрен, проверка ручная.
5. Сохранить и начать с фразы «проверь сайт example.ru на соответствие
   требованиям РФ» — модель задаст вопросы и поведёт по чек-листу.

## GPT: обычный ChatGPT без создания GPT

Вставить компактную версию из
[`openai/custom-instructions.md`](../openai/custom-instructions.md) в
**Settings → Personalization → Custom Instructions**, в поле «How would you like
ChatGPT to respond?». Она укладывается в лимит 1500 символов.

Чек-лист в этом варианте не загружается — модель ведёт проверку по памяти о
структуре. Если нужен полный перечень пунктов, приложите
`manual-checklist.md` файлом в конкретный диалог.

## GPT: через API

В `system` положить текст из блока `System Prompt`, следом — содержимое
`manual-checklist.md`. Обе части текстовые, инструменты не требуются.

## Зависимости

Их нет — всё работает на стандартной библиотеке Python 3.10 и новее.

Опционально ставится Playwright: без него сбор идёт без рендера страниц, и
правила про cookie-баннер, состояние чекбоксов и сетевые запросы уходят в
`UNKNOWN`. С ним покрытие полное.

```bash
pip install playwright && python -m playwright install chromium
```

`PyYAML` тоже не обязателен: рядом с `rules.yaml` и `signatures.yaml` лежат
сгенерированные JSON-двойники, которые читаются стандартной библиотекой.
YAML остаётся форматом для правки человеком.

## Проверка установки

```bash
cd ~/.claude/skills/pepper-ru-web-compliance
python3 scripts/selftest.py                # регрессии детекторов, без сети
python3 scripts/registries.py probe        # что доступно с этой машины
python3 scripts/collect.py https://example.ru --out /tmp/a --max-pages 5
python3 scripts/detect.py --artifacts /tmp/a --out /tmp/f.json
python3 scripts/render.py --findings /tmp/f.json --out-dir /tmp/report --format md,html,pdf
```

Раскладку чек-листа в HTML и PDF выбирает `--layout`: `stacked` (по умолчанию),
`twoline` или `wide`.

Если `probe` показывает недоступные реестры — это нормально за пределами РФ.
Часть источников подхватится с зеркала, для остальных смотрите
`references/registries.md`.
