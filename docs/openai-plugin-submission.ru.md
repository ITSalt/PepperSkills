# Подача PepperSkills в каталог OpenAI

Официальный путь для публичного плагина — [портал подачи плагинов](https://platform.openai.com/plugins).
Для этих пакетов выбирается тип `Skills only`: MCP-сервер и публичный endpoint
не нужны.

Перед подачей:

1. Запустить `scripts/build-plugins.sh pepper-ru-web-compliance` и проверить
   архив после распаковки в чистый каталог.
2. Подготовить карточку: название, короткое и полное описание, логотип,
   категорию, сайт, поддержку, privacy policy, terms и доступные страны.
3. Подготовить стартовые запросы и минимум пять положительных и три отрицательных
   тест-кейса. Для каждого указать запрос, ожидаемое поведение, форму результата
   и фикстуры; для отрицательных — ожидаемое уточнение или безопасный отказ.
4. В организации OpenAI подтвердить личность издателя. Отправителю требуется
   право `Apps Management: Write`.

В портале открыть `Create plugin → Skills only`, загрузить zip-файл, проверить
импортированный `SKILL.md`, ссылки, скрипты и результаты автоматического
сканирования, заполнить карточку и выбрать `Submit for Review`. Подача запускает
ревью, но не публикует пакет сразу. После одобрения издатель отдельно нажимает
публикацию; тогда плагин появляется в общем каталоге ChatGPT и Codex.

Каждая новая версия инструкций или ресурсов требует нового version, повторного
ревью и публикации. Локальный marketplace из `.agents/plugins/marketplace.json`
используется для разработки и тестирования и не заменяет публичную подачу.

Источники: [упаковка плагина](https://developers.openai.com/plugins/build/plugins),
[подача и публикация](https://developers.openai.com/plugins/deploy/submission),
[Agent Plugins specification](https://agent-plugins.org/specification).
