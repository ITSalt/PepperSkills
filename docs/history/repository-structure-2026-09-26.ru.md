# Реорганизация PepperSkills: результат этапа A

Дата: 26 сентября 2026. Статус: структура этапа A подготовлена в ветке
`codex/repository-structure`; публикация и удаление старых путей не выполнялись.

## Каноническая структура

Для каждого продукта единственный редактируемый skill находится в
`plugins/<name>/skills/<name>/`. Манифест плагина, сгенерированные адаптеры
клиентов, чат-шаблоны и документация находятся рядом в `plugins/<name>/`.
Поставочные ZIP создаются в `dist/<name>/<version>/`. В Git хранятся готовые
совместимые файлы, чтобы установка не требовала локальной сборки.

## Почему исходное предложение заменено

В исследовании рассматривались общие каталоги и симлинки, менеджеры skills,
проектная установка, плагины и marketplaces, ZIP-загрузка и чат-адаптеры.
Это способы доставки одного источника, а не основания для дублирования методики
по брендам. Сохранена уже существующая структура `plugins/<name>/skills/<name>/`:
она сохраняет marketplace-пути и не требует новых `shared`, overlays или пустых
брендовых папок. Исходное предложение ниже по ссылке — исторический материал;
оно не является текущим планом миграции.

## Что изменено в этапе A

- Сохранены marketplace-пути и существующие каталоги `plugins/<name>/`.
- Установочные схемы и миграция общих каталогов/симлинков описаны в одной
  инструкции на русском и английском языках.
- Семь корневых переходных ссылок сохранены; команды безопасной установки
  проверяют цель и тип пути. Пользовательские ссылки не меняются автоматически.
- Версии Prompt Engineer подготовлены как `2.5.0`; Creative Mode и Compliance
  остаются `2.0.0`. Источником версии плагина является `plugin.json`.
- Для чат-адаптеров используется один генератор и явные Markdown-шаблоны;
  манифесты клиента, listing, LICENSE-копии и INSTALL-указатели проверяются
  генераторами без побочных записей в режиме `--check`.
- Сборщики читают канонические источники и выдают standalone `.zip` и
  `.plugin.zip` с детерминированными метаданными в `dist/`.
- Добавлены офлайн-защита и CI-проверки на Ubuntu/Python 3.10 и 3.12 и
  macOS/Python 3.12 с межсредовым сравнением контрольных сумм.
- Прежние архивы `.skill` восстановлены побайтно из исходного commit
  `4128fe67f1aa4b812d000b5e61eada0a5e21bffc`. Три отличавшихся файла сохранены
  локально в игнорируемом `artifacts/pre-migration/2026-09-26/` с SHA-256 в
  `manifest.json`; эти резервные копии не включаются в пакеты.
- Исторические release notes перенесены в `docs/releases/`; завершённые отчёты
  модернизации — в `docs/history/` без переписывания их результатов.

## Пути на переходном этапе

| Старый путь | Канонический путь |
| --- | --- |
| `<name>/anthropic/` | `plugins/<name>/skills/<name>/` |
| `<name>/openai/` | `plugins/<name>/adapters/chat/` |
| `pepper-prompt-engineer/chat-prompt.md` | `plugins/pepper-prompt-engineer/adapters/chat/chat-prompt.md` |
| `RELEASE-NOTES-v1.4.*.md` | `docs/releases/` |
| `docs/modernization-*.ru.md` | `docs/history/` |

Переходные ссылки останутся до отдельного этапа B. Его условия: успешная загрузка
ZIP в целевые клиенты, публикация заменяющих пакетов для трёх продуктов и
переходный выпуск с предупреждением о переносе. Старые Releases и теги при этом
сохраняются. Локальная сборка не считается подтверждением установки или
публикации.
