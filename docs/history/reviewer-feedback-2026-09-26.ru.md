# Доработки по замечаниям ревьюера — 26 сентября 2026

Этот отчёт фиксирует локальную проверку до выпуска. Последующие GitHub-релизы
описаны в [записи выпуска](../releases/2026-09-26-feedback.md); контрольные суммы
ниже относятся к сборкам на момент этой локальной проверки.

Подготовлены локально: RU Web Compliance **2.1.0**, Creative Mode **2.0.1** и
Prompt Engineer **2.5.1**. В двух последних изменена карточка OpenAI, методика
не менялась. Подача в каталог и публикация новых версий не выполнялись.

## Что изменилось

- Пользовательские команды Compliance, docstrings и подсказки используют
  `uv run --no-project`; браузерные команды явно добавляют Playwright.
- Добавлены каркас публичной декларации ЗИ и варианты интерфейса по целям и
  основаниям, без автоматического признания законности по наличию декларации.
- Справочник `not-required-ru.md` предлагает удаление ненужных механизмов с
  проверкой применимости норм, требований сервисов и других юрисдикций.
- SKILL.md сокращён с 1343 до 897 слов. Задана краткость находок и смыслового
  анализа; цитаты в рендерере больше не обрезаются на 300-м символе.
- Итоги, метки и открытые задачи учитывают принятую смысловую проверку.
  Машинный `status` сохранён в findings и виден в отчёте. PASS/NA закрывают
  только проверенный пункт; FAIL/UNKNOWN не скрываются. Изменённые артефакты
  аннулируют старую оценку, неполное покрытие сервисов не даёт PASS.
- Pi описан в русской и английской инструкции: общий каталог skills, вызов,
  обновление через `/reload`, отключение и проверка дубликатов.
- Лимиты финальной карточки OpenAI проверяются локально. Короткие описания:
  Compliance — 29, Creative Mode — 28, Prompt Engineer — 21 символ.
- Перегенерированы версии, манифесты, listing, checklist/JSON и чат-адаптеры.
  Изменения текстов адаптеров явно внесены в контрольные фикстуры.

## Проверено

Полный `scripts/check.sh` завершился с кодом 0 после итоговых правок:

- 51 самопроверка Compliance;
- 8 регрессионных тестов, включая принятые PASS/FAIL/UNKNOWN/NA, неполную
  оценку, устаревшую привязку, незакрытое соседнее правило, сохранность цитат,
  HTML-якоря и отсутствие изменения исходных машинных результатов;
- 8 сценариев подачи; схема 11 сценариев Prompt Engineer (не ответы модели);
- границы ограничений карточки OpenAI и контрольные тексты адаптеров;
- инструкции и безопасные симлинки в Bash/Zsh;
- все шесть ZIP, воспроизводимость и отказ сборщиков при устаревших производных;
- отсутствие сетевых обращений и изменений исходников во время полного теста;
- `git diff --check`.

Тесты выполнены существующим Python с подготовленными зависимостями из
`/tmp/pepperskills-ci-deps`; точный запуск через uv в этой среде не проверен:
uv отсутствовал, временная загрузка uv/Playwright была остановлена без
установки в пользовательские проекты. Лог полного прогона в этой сессии:
`/tmp/pepper-feedback-check-final.log`.

На искусственной фикстуре дополнительно сформирован HTML/Markdown-отчёт:
один принятый смысловой PASS и один отдельный незакрытый WARN. Встроенный
браузер запретил открытие локального HTML по политике URL; визуальная проверка
HTML/PDF не выполнена. Браузерный сбор, живые ответы модели, установка/
обновление/отключение в Pi и marketplace-клиентах остаются отдельной приёмкой.
GitHub CI для этих незакоммиченных изменений не запускался.
