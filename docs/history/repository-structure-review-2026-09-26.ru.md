## Уточнения к ревью

- Русские подписи внутри английского полного Creative Mode и висячие ссылки
  существовали уже в `e2c7d4f`; это не новый дефект объединённого генератора.
  Тем не менее их исправление необходимо для текста, вставляемого в чат. Шесть
  точечных замен ссылок и новая команда пересборки отражены в CHANGELOG и golden-fixture.
  Остальные байты тел промптов, включая пустые строки, восстановлены.
- Статистические числа и устаревшие инструкции пересборки `.skill` из старого
  troubleshooting не переносились как новые гарантии. Сохранены диагностические
  действия и ссылки на канонические ограничения методики.
- `v1.4.1-1-g4128fe6` — проверенное обозначение Git-ревизии прежних сборок,
  а не утверждение, что все три skill имели одинаковую продуктовую версию.
  Старые архивы не содержат единого поля версии; точная идентификация — commit
  и контрольные суммы, а не приписанная им текущая версия плагина.
- Для истории выбран разрешённый в замечании вариант: явная пометка superseded
  и ссылка на итог, без переписывания первоначальных выводов задним числом.

## Проверки и следующий шаг

Локальная среда: macOS, Python 3.14.5. Для воспроизведения установите зависимости
из `scripts/requirements-build.txt` в выбранное Python-окружение и запустите:

```bash
python3 -m pip install -r scripts/requirements-build.txt
bash scripts/check.sh
```

В CI зависимости устанавливаются на этапе подготовки. Офлайн-набор блокирует и записывает
сетевые попытки, в том числе в дочерних Python-процессах. Команды менеджеров,
живые сайты, браузерная приёмка и загрузка ZIP клиентом не выдаются за офлайн-тесты.

Итоговый локальный прогон: **PASS**. Дополнительно проверены исходные legacy-байты,
резервные SHA-256 и семь переходных симлинков. Локальный прогон не доказывает
совместимость Linux/Python 3.10/3.12: это проверяют три job в GitHub workflow,
а четвёртый сравнивает хэши между средами.

Ветка отправлена на GitHub. [Прогон CI для `0749e2e`](https://github.com/ITSalt/PepperSkills/actions/runs/36254126554)
завершился успешно: Ubuntu/Python 3.10, Ubuntu/Python 3.12, macOS/Python 3.12
и сравнение SHA-256 архивов между средами. Это подтверждает межплатформенную
воспроизводимость проверенных пакетов. Клиентская приёмка и выпуск проверяются
отдельно; старые пути сохраняются до этапа B.
