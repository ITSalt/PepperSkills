# RU Web Compliance 2.1.1

Старая ссылка `pepper-ru-web-compliance/pepper-ru-web-compliance.skill`
отдавала 1.0.1. Теперь этот файл совпадает с standalone ZIP 2.1.1; CI
отклоняет выпуск, если совместимый архив отстал от текущих исходников.

Скачать: [релиз 2.1.1](https://github.com/ITSalt/PepperSkills/releases/tag/pepper-ru-web-compliance-v2.1.1).
Для Claude используйте `pepper-ru-web-compliance.zip` и замените существующий
скилл. Вариант `.plugin.zip` предназначен для установки плагина.

## Исправлено

- Удалена суммарная «верхняя граница санкций»: связанные правила больше не
  складываются, повторность не попадает в отдельный расчёт резюме. Условия
  санкций остаются рядом с соответствующим правилом.
- Убраны повторяющиеся доказательства, одинаковые блоки оснований и
  назидательные предупреждения. Действия находятся в плане; объединённая
  задача сохраняет инструкции каждого правила. Задачи без fix_hint получают
  действие из инструкции проверки.
- В план не копируются цитаты и длинные параметры сетевых запросов.
  Печать стала компактнее, с переносом длинных адресов.
- Ссылка «Войти» или другая форма входа на странице больше не исключает
  форму подписки/заявки из проверки согласия.
- Политика стороннего сервиса больше не принимается автоматически за
  политику владельца сайта. Собственный домен приёмника больше не даёт
  автоматический PASS для географии и размещения базы.
- Рекомендация заменить капчу больше не выдаётся безусловно при находке шрифтов.
- Findings и отчёты содержат версии скилла/детектора/генератора и SHA-256
  правил. Старые или неполные findings отклоняются до записи файлов;
  `--allow-legacy` разрешает только явно помеченный просмотр снимка.
- Проверка согласованности выявляет подтверждённое согласие при незакрытом
  дефекте его получения и неподтверждённый машинный PASS о географии.
- Ответ в чате ограничен инструкцией: 3–4 предложения, до 100 слов.

## Проверка и границы

Полный локальный `scripts/check.sh`: самопроверки детекторов, 8 прежних
регрессий, 10 новых регрессий на ошибки отчётов, 8 сценариев подачи, схемы,
тексты адаптеров, установка, извлечённые пакеты и воспроизводимость ZIP.

Дополнительно проверен синтетический HTML/PDF в Chromium: рабочие якоря,
отсутствие переполнения по ширине, отсутствие пустых действий и повторов
параметров запроса; страницы PDF просмотрены визуально.

Это проверка кода и тестового документа. Повторные обходы metallik.ru и
omnidata.ru и выполнение новой версии внутри Claude не проводились.
Справочник санкций не проходил новую юридическую сверку; дата обхода больше
не объявляется датой подтверждённой актуальности законодательства.

## Выпуск совместимого архива

После сборки ZIP выполнить `python3 scripts/sync-compat-archives.py --write`.
Проверка `--check` выполняется в CI без изменения файлов. Другие исторические
`.skill` не затронуты. Прежние релизы сохранены.
