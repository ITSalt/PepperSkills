# RU Web Compliance 2.2.0 — доказательства и рекомендации

Версия исправляет переход от сетевых наблюдений к рекомендациям.
[Релиз и пакеты 2.2.0](https://github.com/ITSalt/PepperSkills/releases/tag/pepper-ru-web-compliance-v2.2.0).
Проверка установленного пакета внутри Claude не выполнялась.

## Изменения

| Требование | Реализация |
| --- | --- |
| Сохранять контекст запроса | Сборщик пишет страницу, сценарий, фрейм, доступный инициатор CDP, тип содержимого и известные имена полей без значений. |
| Не считать любой POST отправкой формы | Детектор различает нативную отправку, CSP, предполагаемую аналитику и неизвестное назначение. Нет исключения целых доменов и ограничения только POST/сторонними адресами. |
| Не объявлять географию БД по домену | PDN-011 и INF-003 остаются UNKNOWN без отдельной оценки, документов и конфигурации; собственный домен и российский бренд не дают PASS. |
| Разделять проверку и исправление | WARN/UNKNOWN идут в раздел V. Только подтверждённое исправление получает P0–P3. Общий fix_hint не применяется к открытым вопросам. |
| Согласовать смысловую оценку | Новый контракт summary + action: verify/fix, text, evidence, acceptance, locations. Источники действия должны входить в источники оценки; fix допустим при FAIL и известном месте изменения. |
| Развести наблюдение и место правки | Запросы отображаются как «Где наблюдалось». «Где менять» содержит только подтверждённые цели изменения из принятой оценки. |
| Содержательная приёмка | Для локализации — схема потоков и подтверждение размещения/конфигурации баз; JSON не является критерием законности. |
| Старые данные | Журналы без нового контекста помечаются неполными. Старые оценки остаются читаемыми, но без нового действия не создают предписаний на исправление. Изменение артефактов отменяет прежнюю оценку по SHA-256. |

Изменены канонические источники compliance; производные правила JSON, чек-лист,
чат-адаптеры и манифесты синхронизированы. Совместимый `.skill` соответствует ZIP.
Остальные скиллы не изменялись. Новая юридическая сверка всех норм и санкций
не проводилась; дата проверки кода не является датой такой сверки.

## Проверка

- Самопроверки детекторов и 29 unittest-регрессий: 8 прежних, 10 проверок
  качества отчёта, 11 новых сценариев сетевых доказательств/смысловых действий.
- Полный `scripts/check.sh` прошёл в изолированном снимке HEAD `1283bab` с этой
  доработкой: проверки схем, синхронизации, чат-адаптеров, 8 сценариев подачи,
  установки, распакованных ZIP, воспроизводимости и отказа сборки на устаревших
  производных файлах без изменения исходников. Сетевых обращений offline gate нет.
- Изоляция потребовалась из-за оставшегося локального каталога
  `plugins/pepper-orchestrator` без манифеста. Он не удалялся и в сборку не включался.
  Перед копированием ZIP выполнено побайтовое сравнение всех исходников compliance
  между проверенным снимком и рабочим каталогом.
- Chromium: перехваченные синтетические страницы, реальные нативные GET/POST-формы,
  AJAX, инициаторы и iframe, повторное подключение сборщика. Все запросы тестовых
  страниц обслуживались перехватчиком; внешние сайты и провайдеры не вызывались.
- Markdown/HTML согласованы; якоря уникальны и доступны, горизонтального
  переполнения HTML нет. PDF из того же HTML содержит 8 страниц; текст проверен,
  все страницы просмотрены на контактном листе, страница локализации — отдельно.

Это проверка скилла и синтетического примера из шести адресов присланного
отчёта. Первичные артефакты того запуска не предоставлены. Повторный аудит
metallik.ru и проверка установленного пакета внутри Claude не выполнялись.
Для AJAX связь с формой требует отдельного подтверждения; автоматический
сборщик не заполняет и не отправляет формы проверяемого сайта. Недоступный
контекст worker/iframe остаётся неизвестным. Служебный запрос не объявляется
безопасным или свободным от персональных данных.
