# PepperSkills v1.4.0 — `pepper-ru-web-compliance` 1.0.0

Третий публичный скилл: проверка сайта на соответствие требованиям российского
законодательства.

## Что делает

Открывает сайт как обычный посетитель, читает разметку, сетевые запросы, cookie
и правовые документы, сверяет упоминания с госреестрами — и выдаёт два
документа:

- **аналитическую записку** для владельца и юриста: резюме, оценка риска в
  рублях, чек-лист по всем правилам с нормой и вилкой штрафа, разбор каждого
  нарушения с доказательствами, раздел «что проверить вручную» с конкретной
  процедурой;
- **план правок** для агента-разработчика: задачи по убыванию риска, у каждой
  место изменения и проверяемый критерий приёмки.

## Покрытие

44 правила: авторизация (п. 10 ст. 8 ФЗ-149, ст. 13.55 КоАП — вход через Google,
Apple, Telegram), плашки иноагентов и запрещённых организаций, символика Meta,
персональные данные по 152-ФЗ (политика, согласия, трансграничная передача,
локализация базы, уведомление РКН), cookie и трекеры, инфраструктура, реквизиты
продавца.

22 правила закрывает скрипт, 12 гибридные, 8 смысловые, 2 справочные.

## Как это устроено

Четыре слоя: сбор фактов → госреестры → детекторы → смысловой анализ. Скрипты
фиксируют наблюдаемое, модель квалифицирует спорное.

Три правила, которые важнее удобства: статус без доказательства не выставляется;
нехватка данных — не `PASS`; происхождение данных едет вместе с выводом, и по
неофициальному источнику вывод не поднимается выше `WARN`.

## Госреестры

Пять реестров Минюста и ФСБ. Хосты `*.gov.ru` отвечают только с российских
адресов, поэтому источник разрешается по цепочке: официальный сайт → официальный
через прокси пользователя (`PEPPER_RU_REGISTRY_PROXY`) → публикуемое зеркало
[`ITSalt/ru-registries-mirror`](https://github.com/ITSalt/ru-registries-mirror)
→ кэш. Архивные снимки в поставку не входят намеренно: устаревший реестр даёт не
«данных нет», а тихое ложное «упоминаний не найдено».

## Установка

- **Claude Desktop / claude.ai** — скачать `pepper-ru-web-compliance.skill` из
  этого релиза, загрузить через *Settings → Capabilities → Skills → Upload*.
- **Claude Code** — распаковать в `~/.claude/skills/pepper-ru-web-compliance`.
- **OpenAI** — `openai/system-prompt.md` и чек-лист ручной проверки на 25
  пунктов.

Зависимостей нет: стандартная библиотека Python 3.10+. Playwright опционален и
расширяет покрытие.

## Границы

Скилл выполняет техническую проверку и не является юридической услугой.
Два правила штатно остаются без автоматического вывода — реестр запрещённой
информации (машиночитаемая выгрузка только для операторов связи) и реестр
операторов РКН (отвечает только с российских адресов); по обоим печатается
инструкция ручной проверки со ссылкой на форму.
