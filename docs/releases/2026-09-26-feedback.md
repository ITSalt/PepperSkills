## Changes / Изменения

Compliance 2.1.0 unifies uv execution guidance, adds a public legitimate-interest
declaration scaffold and conditional interface/removal guidance, and documents Pi.
Accepted semantic review now determines report totals and outstanding actions,
while machine observations and evidence remain visible. Instructions are shorter;
quotes retain their qualifying conditions. OpenAI final listing limits are checked.

Compliance 2.1.0: единый запуск через uv, каркас декларации ЗИ, варианты интерфейса,
рекомендации по удалению ненужного с проверкой применимости, инструкция Pi.
Принятая смысловая оценка учитывается в итогах и незавершённых задачах;
машинные наблюдения сохраняются. Декларация сама по себе не даёт PASS.

Creative Mode 2.0.1 and Prompt Engineer 2.5.1 shorten OpenAI listing subtitles
to meet final directory limits. Their skill methodologies remain unchanged.

## Validation / Проверки

The full offline suite passed locally: 51 Compliance self-checks, 8 regression
tests, 8 submission fixtures, listing limits, chat goldens, installation examples,
six ZIP packages, reproducibility, and read-only builder checks. GitHub CI is
checked before publishing the releases; see the workflow runs for the tagged
commit in [repository checks](https://github.com/ITSalt/PepperSkills/actions/workflows/check.yml).

Exact uv runtime execution, live browser/PDF visual acceptance, model responses,
and installation/update/disable in real clients were not verified for these new
versions. Previous Claude web ZIP acceptance applies only to the
[transition releases](2026-09-26-transition.md).

Проверки кода и упаковки не заменяют клиентскую приёмку. Подробности локальной
проверки: [отчёт по доработкам](../history/reviewer-feedback-2026-09-26.ru.md).
GitHub Release не является публикацией в каталоге OpenAI; подача туда не выполнялась.
