# Pepper Orchestrator 0.15.0: ограниченные исследования, проактивный контроль и локальное продолжение

3 ноября 2026 года. Публичный preview, тег [`pepper-orchestrator-v0.15.0`](https://github.com/ITSalt/PepperSkills/releases/tag/pepper-orchestrator-v0.15.0).
[English](pepper-orchestrator-0.15.0-release.md).

## Зачем

Координатор Codex шесть часов вёл исследовательский пакет и так его и не сдал. Каждая волна
порождала смежный вопрос, собственные коммиты журнала снова будили координатора, а
экспериментальная часть пакета держала статическую, которая была нужна зависимым пакетам.
Релиз ограничивает исследование, явно назначает владельца каждого оставшегося критерия и
сохраняет таймер как инструмент управления координатора, а не убирает его.

## Что изменилось

- **Контракт исследования** ([research.md](../../plugins/pepper-orchestrator/skills/pepper-orchestrator/references/research.md)), общий для Claude Code и Codex и для обоих исполнителей (сабагенты, запущенные сессии): не больше 8 замороженных критериев, одна волна и одна адресная доработка, вердикт по каждому критерию. `partial` передаёт каждый нерешённый критерий пакету-владельцу с условием; пакет становится ACCEPTED/DONE, зависимые продолжают работу. `blocked` требует условия разблокировки, а `unblock` возвращает только к проверке.
- **Проактивный watcher.** Новый факт будит координатора сразу; необработанное действие повторяется через `interval_seconds`, ожидание только владельца — раз в шесть интервалов. Собственные коммиты координатора фактами не считаются. Каждое пробуждение — контрольный тик: прогресс по критериям и бюджету, простои, затем решение.
- **Детектор простоя** ([#45](https://github.com/ITSalt/PepperSkills/issues/45)): действие `stalled` для пакетов, ждущих исполнителя, без изменений файлов, коммитов, индекса и push дольше `--stall-minutes` (по умолчанию 45), пока сессия не занята, и для исследований, ответы которых не записаны.
- **Локальное продолжение в Codex** ([local-continuation.md](../../plugins/pepper-orchestrator/skills/pepper-orchestrator/references/local-continuation.md)): сохранённый выбор auto/manual, наследование прав координатора и автоматический запуск исполнителей в обычных локальных сессиях.
- **Claude Code:** `/goal`, `/loop`, `ScheduleWakeup` и `CronCreate` разрешены с измеримым условием и пределом из пакета; `resume` сверяет их с реестром.

CI в pull request покрывает Linux, macOS и Windows.

**В этом релизе не повторялись:** живая приёмка private owner на Linux/macOS, записанная для
[0.14.0](pepper-orchestrator-0.14.0-private-owner.ru.md), и живой драйвер локального продолжения
`scripts/test-orchestrator-local-continuation.py`, которому нужен запущенный сервер Codex. Оба пути
используют изменённый общий scheduler; их поведение покрыто offline-наборами выше, а не новым
прогоном с моделью. Релиз остаётся preview.
