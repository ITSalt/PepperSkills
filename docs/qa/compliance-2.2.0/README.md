# Синтетическая приёмка 2.2.0

Это тест скилла, не аудит metallik.ru. Шесть адресов взяты из присланного
отчёта; значения параметров заменены тестовыми маркерами. Все остальные
правила вне примера отмечены как неприменимые к тестовому сценарию.

`synthetic-findings.json` показывает также искусственный случай: машинный
PASS по наличию чекбокса и смысловой FAIL по его связи с формой. Это проверка
согласованности отображения, не утверждение о реальном сайте.

- `synthetic-report.md`, `.html`, `.pdf` — один пример в трёх форматах.
- `localization.png` — блок проверки размещения БД.
- `pdf-contact-sheet.jpg` — все 8 страниц PDF, просмотрены визуально.
- `checks.json` — результаты Chromium на перехваченных страницах.
- `offline-check.log` — полный gate из изолированного снимка с доработкой.

Воспроизводимый браузерный сценарий — `scripts/test_network_browser.py`
внутри скилла. Полная запись проверки и ограничения —
[release notes](../../releases/2026-09-28-compliance-2.2.0.md).
